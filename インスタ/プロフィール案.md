# インスタ プロフィール案

テーマ：服のトレンドを動画で紹介する発信

---

## ① 説明欄（プロフィール文）の案

インスタの説明欄は **150文字まで** です。
最初の1〜2行で「何のアカウントか」が伝わるようにしています。
【　】の部分は、決まったら書き換えてください。

### 案A：シンプル・わかりやすさ重視
```
今のトレンド服を、動画でサクッと紹介しています👕
「今なに着ればいい？」がすぐわかる
着こなし・組み合わせのヒントも発信
【毎週○曜日】更新
保存してお買い物の参考にどうぞ
```

### 案B：親しみやすさ重視
```
服が好きで、トレンドを動画にまとめています🎬
流行りの服・着こなしを、見てすぐわかる形でお届け
「これ良さそう」と思ったら保存してください
気になる服のリクエストはDMへどうぞ
```

### 案C：AI動画も前に出すパターン
```
服のトレンドを動画で発信中👕🎬
AIも使って、わかりやすい動画を作っています
今っぽい服・組み合わせをチェックできます
【毎週○曜日】更新／ティックトックもやっています
```

### 説明欄に入れると良いもの（チェック用）
- [ ] 何のアカウントか（服のトレンドを動画で紹介）
- [ ] 見た人にとって良いこと（何を着ればいいかわかる、など）
- [ ] 更新する日・頻度（決まっていれば）
- [ ] ティックトックへの案内
- [ ] 連絡先・DMの案内（お仕事の依頼を受けるなら）

## ② アイコンの案

アイコンはとても小さく表示されるので、
**「ぱっと見でわかる」「シンプル」** が大事です。

### 案1：ハンガー＋再生ボタン
- ハンガーの形の中に、動画の再生マーク（▶）を入れる
- 「服」と「動画」が一目で伝わります
- 色：白い背景に黒、または黒い背景に白

### 案2：アカウント名の頭文字ロゴ
- アカウント名の頭文字1〜2文字を、太めの文字で真ん中に
- おしゃれでブランドっぽい印象になります
- 色：ベージュやグレーなど、服に合う落ち着いた色

### 案3：ご本人の写真（顔出しする場合）
- 服を着ている上半身の写真
- 「この人が紹介している」と伝わり、親しみを持たれやすいです
- 背景は無地にすると、小さくても見やすいです

### 案4：服のシルエットのイラスト
- Tシャツやジャケットの形をシンプルな線で描く
- 色を1〜2色にしぼると、すっきり見えます

### アイコンのコツ
- 文字は入れても1〜2文字まで（小さいと読めないため）
- ティックトックとアイコンを同じにすると、同じ人だと気づいてもらいやすいです
