# 英語の宿題の使い方

## 準備（最初に1回だけ）
1. 提出用のひな形（Word や PDF）を `2_フォーマット/` に入れる

## 毎回やること
1. 先生からの課題ファイルを `1_課題/` に入れる
2. Claude に「英語の宿題やって」と言う
3. Claude からの質問（意見・体験など）に日本語で答える
4. `4_完成/` にできたファイルを確認して、自分で提出する

## Claude がやること・やらないこと
- やる：課題を読む、意見を聞く、英語で書く、フォーマットに入力する、語数を数える
- やらない：体験をでっち上げる、ひな形を上書きする、提出する

※ 授業によっては AI の使用が禁止されていることがあります。課題に書いてあれば Claude が知らせます。
