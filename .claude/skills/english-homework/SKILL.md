# 英語の宿題（英作文・エッセイ）の進め方

フォルダはすべて `英語の宿題/` の中を使う。

| フォルダ | 中身 |
|---|---|
| `1_課題/` | 先生からの課題（PDF・Word） |
| `2_フォーマット/` | 提出用のひな形（Word・PDF） |
| `3_メモ/` | 本人の意見・体験のメモ（Claude が作る） |
| `4_完成/` | 書き上げた提出用ファイル（Claude が作る） |

## 手順

### 1. 課題を読む
- `1_課題/` の新しいファイルを読む（PDF は `pdftotext -layout`、Word は python-docx）。
- 次を書き出して本人に見せる：テーマ・語数（または文字数）・締切・書式の指定・注意事項。
- **課題文や注意事項に「AIの使用禁止」などがあれば、そこで止めて本人に伝え、進めるか聞く。**
- 読めない・あいまいなところは推測せず質問する。

### 2. 本人の意見・体験を聞く（ここは飛ばさない）
- エッセイの中身は本人の考えと本当の体験だけで作る。体験をでっち上げない（CLAUDE.md のルール）。
- 日本語で、短い質問を3〜5個まとめて聞く。例：
  - このテーマに賛成・反対、どちらですか？
  - そう思う理由を2つくらい教えてください
  - 関係する体験があれば教えてください（なければ「なし」で大丈夫です）
- 答えを `3_メモ/<課題名>_メモ.md` に保存する。

### 3. 英語で書く
- 大学の授業レベルの、自然で読みやすい英語。むずかしすぎる単語は避ける。
- 基本の形：導入（主張）→ 理由・具体例 → まとめ。課題に指定があればそれに従う。
- 語数は指定の範囲に必ず収め、数えて確認する。
- 本人が言っていない数字・出来事・引用は入れない。必要そうなら質問する。

### 4. フォーマットに入力して保存
- `2_フォーマット/` のひな形は**絶対に上書きしない**。コピーを `4_完成/<課題名>_完成.docx` などの名前で作って、そこに入力する。
- Word：python-docx で、元の文字の大きさ・フォント・行間を崩さずに、タイトル・本文などの欄に入れる。
- PDF：入力欄（フォーム）があればそこに入れる。なければ本人にどうするか聞く（Word で作り直す、など）。
- 名前は CLAUDE.md の名前を使う。**学籍番号・授業名・先生の名前などは、書かれていなければ質問する**（推測で埋めない）。
- 同じ名前のファイルが `4_完成/` にあるときは、上書きする前に止まって、はい・いいえで聞く。

### 5. 報告
本人に次を伝える：
- 保存したファイルの場所
- 語数
- 本文の日本語訳（ざっくりでよい）
- 本人に確認してほしいところ（体験の内容が合っているか、など）

提出は本人がする。Claude は提出・送信をしない。
